# FIRST X&XI — plain HTML, CSS, and JavaScript

No TinaCMS, framework, dependency installation, or build step.

## Open on your computer
Extract the ZIP first. Open `index.html` while keeping `styles.css`, `script.js`, and `assets/` alongside it. Alternatively, open `OPEN-PREVIEW.html`, which includes the styles, scripts, and fonts in one file. Stock photos require Internet access.

## GitHub and Vercel
Upload this folder’s contents to your GitHub repository root. In Vercel select framework **Other**, clear any previous install and build commands, and set output directory to `.`. Remove the old Tina project files when replacing that version. No environment variables are needed. The included vercel.json is for a static site.

Includes the original design and interactions, info@firstxandxi.com, MMA, and the requested ticker wording. The phone number is removed. Inquiry forms prepare an email draft; they do not send or store submissions. The logo remains a typographic recreation. Fonts and their licenses are bundled in assets; photos load from Unsplash.
